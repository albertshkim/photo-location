코드 작성을 시작하려면 App.js 파일을 여세요.
 QR 코드를 스캔하면 휴대폰이나 태블릿에서 변경된 내용을 바로 미리 확인할 수 있으며, iOS 또는 Android 에뮬레이터를 사용할 수도 있습니다.

작업이 완료되면 Save(저장) 를 클릭한 후 링크를 공유하세요!

Expo에서 제공하는 모든 기능을 사용해 보고 싶거나, 자신이 사용하는 에디터에서 작업하고 싶다면 프로젝트를 Download(다운로드) 한 후 Expo CLI와 함께 사용할 수 있습니다.

Snack에서 생성된 모든 프로젝트는 공개적으로 이용 가능합니다. 따라서 이 프로젝트의 링크를 다른 사람과 쉽게 공유할 수 있으며, <> 버튼을 사용해 웹 페이지에 삽입할 수도 있습니다.

문제가 발생한 경우 @expo로 문의하거나, Expo 포럼 또는 Discord에서 질문할 수 있습니다.

Snack은 **오픈소스(Open Source)**입니다. 소스 코드는 GitHub 저장소에서 확인할 수 있습니다.

# Sample Snack app

Open the `App.js` file to start writing some code. You can preview the changes directly on your phone or tablet by scanning the **QR code** or use the iOS or Android emulators. When you're done, click **Save** and share the link!

When you're ready to see everything that Expo provides (or if you want to use your own editor) you can **Download** your project and use it with [expo cli](https://docs.expo.dev/get-started/installation/#expo-cli)).

All projects created in Snack are publicly available, so you can easily share the link to this project via link, or embed it on a web page with the `<>` button.

If you're having problems, you can tweet to us [@expo](https://twitter.com/expo) or ask in our [forums](https://forums.expo.dev/c/expo-dev-tools/61) or [Discord](https://chat.expo.dev/).

Snack is Open Source. You can find the code on the [GitHub repo](https://github.com/expo/snack).
